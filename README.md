# econometrics-stats

Coursework in econometrics and behavioural economics from my economics studies, done in Python and Jupyter.

## Contents
| Notebook | Course | Topics |
|---|---|---|
| `innlevering4.ipynb` | SØK1005, assignment 4 | OLS regression with `statsmodels`, t-tests, p-values and confidence intervals on Wooldridge datasets (demand for children, parents' education and birth weight) |
| `SOK2012_term_paper.ipynb` | SØK2012 Behavioural Economics, term paper | Bayesian updating and base-rate neglect, with simulations and plots |

## Tech stack
Python, Jupyter, pandas, NumPy, statsmodels, SciPy, matplotlib, `wooldridge` (datasets).

## How to run
```bash
pip install jupyter pandas numpy statsmodels scipy matplotlib wooldridge
jupyter notebook
```

## What I learned
- Estimating and interpreting regression models, and testing hypotheses at different significance levels.
- Building and reading confidence intervals, and assessing a model critically.
- Using code and simulation to make probability concepts such as priors and base rates concrete.
